# 台本レビュー（初学者役）の依頼文（テンプレート）

`<...>` を埋めて、レビュー担当のサブエージェントに渡す。**音声を作る前に**1回通す
（音声のあとに台本を直すと、作り直した行の尺と語末の時刻が全部ずれる。合成は再現できない）。
講座の教訓ファイル（`templates/course-lessons.md` から作ったもの）の「台本」「TTS」の節を、「講座の教訓」にそのまま差し込む。
依頼文の本体は講座ごとに書き直さない。教訓が増えたら教訓ファイルのほうに足す。

並列で制作しているときは、**レビューは親（取りまとめ役）が回す**（分岐したサブエージェントは、さらにサブエージェントを起動できない）。
**1人のレビュー担当に1レクチャー全部を渡さない。** 止まった。2ユニットずつに分けて並行で回し、1本ごとにファイルへ書かせる。
事実の照合（`fact-check_prompt.md`）は別の担当に渡す（このレビューは一次資料と突き合わせない）。

---

<講座名> の <レクチャー ID の一覧> の台本を、**初学者の受講者の立場で**レビューしてください。<報告の言語>で報告。
**直さず、指摘だけ**を書きます。

**読むもの**（この順）
1. 講座の台本の規約（<規約のファイル>）と、プラグインの `references/quality-standards.md`・`references/tts-readings.md`
2. 講座の用語集・共通の例・検算済みの数（<ファイル>）。台本の言い方と数はここに従う
3. 事実の出典（<一次資料・digest の場所>）の該当箇所。出典に無い断定が出ていないか
4. 直近のレビュー指摘（<過去の指摘ファイルを1〜2本>）。同じ型を拾う
5. 講座の教訓（下に差し込む）

**見る点**（各行を、読み上げられた音声として聞く気持ちで）
1. **定義なしに出てくる語・飛躍・前の文とつながらない説明。** 初学者は、知らない語を聞いても分からない
2. **例の数・計算が正しいか。必ず検算する（Python でよい）。** 用語集・検算済みの数と語りの数が一致するか
3. **体言止め**（述語で言い切っているか）。講師の一人称か（受講者・講師と言っていないか）
4. **TTS が誤読しやすい語**：英字の略語・記号・小数・同音語・「数」の単独使用（かず／すう）・助数詞の読み。
   1音の語（「は」「葉」）や「も」など、**音だけで紛れる言い方**
5. **名前のそろい**：冒頭の一覧（地図）で言った名前と、詳細・要点・まとめで言う名前が同じか
6. **考えてみよう・問いかけ・小テスト**（`references/quiz-authoring.md`）：選択肢ごとに次の表を作ってから判定する。

   | 選択肢 | 語尾・字数 | 問いの語が出るか | 直前の行の否定・写しか | ほかの選択肢と分け合う語 | 常識・慎重さで選べるか |
   |---|---|---|---|---|---|

   - 直前のしくみの言い換え・消去法・鏡写し・選択肢の形の違い・「多いほうが正解（誤答2つの和）」で解けないか
   - 各問に「知っていれば選べる事実の軸」があるか。1つの軸を2問で使っていないか
   - 資料で割れる値・英語の UI の語だけで決まる値を軸にしていないか
   - 解説の「Xは…ので誤り」に主語があるか。解説が次の問いの答えを漏らしていないか
   - 答えに理由があるか／選択肢の番号と答えの数が紛れないか
   - **あなた自身の直し案も、この表に通してから書く**（案をそのまま採って、再レビューで高が出た）
7. **事実**：出典との食い違い、出典に無い断定、頻度の断定（「よく問われる」）、範囲外の話。
   **出どころの断り**（「〇〇のドキュメントでは」「講座の検証では」）が、講座の方針（<出どころを言うか>）に反していないか
8. **尺**：字数の上限（<上限の字数>）を超えていないか。長い1文や1行に定義や新語が詰まっていないか。
   削るなら案を出す（見積りだけで削らない）
9. **前後の回との整合**：用語・言い方・数・例。前の回からの受け渡し
10. **締め**：最後の行が次の回へつながっているか。冒頭・末尾の回なら、各回の要点と一致しているか。
    末尾のまとめの語りが、ユニットの要点と同じ文になっていないか
11. **画面**：機能紹介・使い方の行に、実際の画面（キャプチャ）が割り当てられているか（`quality-standards.md` 29）。
    実践なら、語りが画面に映っているものと合っているか（生成 AI の返答は「今回は」と例として扱っているか）

**講座の教訓**
<course-lessons.md の「台本」「TTS」の節をここに差し込む>

**出力**
- 回ごとに `<レビューの書き出し先>` へ、重大度（高・中・低）・該当行・直し方の案を書く（既にあれば `-2` を付けた別名）
- 最後に短く返す：回ごとの高・中の件数／**耳で確かめる語**／回どうしで食い違っている言い方の一覧
- 新しく分かったこと（0〜3件。教訓ファイルの書式で）。**0件でも「なし」と書く**

**しないこと**
- 台本・共有ファイルを直さない。音声を作らない
- スクリプトに `--help` を渡さない（本処理が走るものがある。使い方はソースを読む）
