# udemy-video-course

動画講座のレクチャーを、スライドとナレーション台本から**AI音声付きの動画**にするハーネス。
座学（スライド中心）と実践（ハンズオン）の両方を扱う。

実践レクチャーでは、制作者が画面録画ソフトで撮る代わりに、**Claude 自身がブラウザを操作して
1状態ずつ静止画を撮り、塗りつぶし・強調を入れてから動画に組む**モードを持つ。

## 全体像

```
[座学]   台本 + pptx ──────────────────────────► make-lecture-movie ──► mp4
[実践]   録画 or 画面操作 ──► record-practice-screen ──► make-practice-movie ──► mp4
                                    │                         │
                         cue_stills（強調を目視）              │
                                    ┌─────────────────────────┘
                                    ▼
                    qa_check / leakcheck ──► transcript-reviewer ──► 差し替え
```

実践の素材づくりには4つのモードがある。クラウドIDEでのコマンド実行、
ドキュメントの読み解き、**Web管理コンソールで作成 → 確認 → 削除まで見せる回（既定）**、
そしてコンソールに画面が無いものだけ CLI で見せる回。
初学者向けには**管理コンソールを主体にし、画面に着くまでの手前（検索 → 候補 → 一覧 → 作成）も撮り、
URL で直接飛ばない**。CLI で作って画面は結果を読むだけの形は「イメージしづらい」と差し戻された。

撮影では**制作者のデスクトップに触らない**（操作はタブグループ内の対象のタブと自分のシェルだけ）。
映り込みは**OCR で黒く塗り、塗った後にもう一度 OCR して 0 件を確かめる**。

静止画から組む回では、**尺を「合成済み音声の実尺 + 2.0秒」で決める**。
文字数の見積もりをそのまま完成尺にすると、余裕分がそのまま無音になる
（実測：見積もりだと沈黙率が2割超、実尺だと約10%）。

## スキル

| スキル | 役割 |
|---|---|
| `make-lecture-movie` | 台本＋pptx → AI音声付き動画。実践は既定でスキップする |
| `make-practice-movie` | 録画＋スライド → 録画に同期した実践動画。区間の粒度・沈黙率・映り込みの作法を含む |
| `record-practice-screen` | Claude が画面を操作して実践の素材（`_rec.mp4`）を撮る。塗りつぶしと強調まで |

## スクリプト

| スクリプト | 何をするか |
|---|---|
| `lecture_movie.py` | 座学の音声合成・スライドPNG化・動画合成。**TTS の失敗・古い音声・モデルの混在があれば終了コード 1 で止まる** |
| `practice_movie.py` | 実践の `calibrate` / `analyze` / `transcript-check` / `build`（同じく止まる） |
| `audio_manifest.py` | 音声フォルダの manifest（本文のハッシュ・モデル・声）。本文が変わった区間だけ作り直し、モデルが混ざる前に止める |
| `deps.py` | 起動時の依存チェック（工程に要るものだけ）。`python deps.py` で、どの Python に何が入っているかを表示する |
| `record` 系 | |
| `build_rec.py` | 静止画フレーム → `_rec.mp4` ＋台本の骨組み。**`--audio-dir` で音声の実尺から尺を決める** |
| `redact.py` | フレームの塗りつぶし（黒ベタ）と強調（周囲を暗くして枠）。`--probe` で座標を先に確認 |
| `box_fit.py` | 強調枠を**文字から 3px 以上離して**置き直し、すき間を検査する。空きが無ければ枠線を 4→3→2px に細くする。誤認する区間は `box_manual.json` で手置き |
| `render_frames.py` | `recipe.json` の塗り・強調を `raw/` に当てて `frames/` を描く（区間ごとの枠線の太さに対応） |
| `cue_stills.py` | 強調を当てた絵をコンタクトシート（4枚/枚）にまとめる。**組み立て前の目視検収**用 |
| `ingest_shot.py` | スクリーンショットを**寸法を確かめてから** `raw/S###.jpg` に取り込む（合わない枚は記録しない）。`fit-window` で表示倍率のある画面の窓の大きさを出す |
| `ocr_mask.py` | 撮ったフレームを OCR で読み、講座の規則ファイルに従って黒ベタで塗る（`masks.json`・`masked/`） |
| `leak_check_ocr.py` | 塗った後をもう一度 OCR し、規則に当たる語が **0 件**であることを確かめる（同じ規則ファイルを読む） |
| `stage_diagram.py` | 段階的に積み上がる構成図を draw.io で生成。**外接矩形を固定**して図の伸縮を防ぐ |
| `QA` 系 | |
| `qa_check.py` | TTS異常（ループ・途切れ・**途中の長い無音**）・沈黙率・体言止め・管理番号を**1コマンド**で検査。静止画から組む回は `--audio-only` の直後にも走らせる |
| `verify_tts.py` | 合成した wav を STT で文字に戻し、**台本と同じ内容か**を照合する（別の文を読む・前置きが付く・冒頭が抜ける合成事故の検出）。Azure Speech（キーレス）を使う |
| `leakcheck.py` | 彩度ベースで映り込みの疑いがある区間を洗い出す（探索） |
| `find_text_leak.py` | 消したい文字列のテンプレートを全編に照合する（特定） |
| `detect_events.py` | 録画から画面が変化した瞬間を秒単位で列挙し、区間境界の候補にする（**実録画のみ**） |
| `shift_lead.py` | ナレーションが画面変化に先行するよう、区間の開始を前倒しする（**実録画のみ**） |
| `完成動画の検査` | |
| `empty_frames.py` | 見出しだけで本体が空の時間が 10 秒以上続く区間を画素で探す（ゲート） |
| `still_report.py` | スライドごとに画が止まっている最長の秒数を測る（報告） |
| `final_sweep.py` | 仕様・尺・音量（LUFS）・無音・黒・cue の補間を全本で1枚の表にする（ゲート） |
| `cue_report.py` | cue（台本の一節で強調を出す同期）を使う講座で、音声との照合結果を分母つきで全数集計する（ゲート） |
| `cue_drift.py` | 同上。matched のまま別の文に当たった cue（誤一致）を拾う（ゲート） |

## 品質ゲート

座学・実践とも、各スキルの「🔴 必ず回す検査」の節が手順の正本。失敗と検出器の対応は
`references/self-improvement.md` の表にまとめてある。実践の要点は次のとおり。

**組み立てる前に2つ、`build` のあとに3つ。**

0. `ocr_mask.py` → `leak_check_ocr.py` — **映り込みを OCR で塗り、塗り残し 0 件を確かめる**（静止画から組む回）
0. `cue_stills.py --sheets` — **強調を当てた絵を全数、目で見る**（静止画から組む回）
1. `qa_check.py <台本>` — 合成音声のループ・途切れ、沈黙率（10〜20%）、体言止め、管理番号
2. `leakcheck.py <動画>` — 映り込みの疑いがある区間（ヒットは必ず目視）
3. `transcript-reviewer` — 画面と台本の突き合わせ、一次ドキュメントでの事実確認

**0 を後回しにしない。** 強調の座標の誤りは数値を読んでも分からない。
実測では4レクチャーで9件見つかり、**座標のレビューで気づけたものは0件**だった。
組んだあとに直すと音声の合成からやり直しになる。

**3 を省かない。** 機械チェックはタイムコードと文字面しか見ないため、
「画面に映っていないものを語っている」「仕様として誤っている」は1件も拾えない。

**どのゲートも抜き取りでは当たらない。** 欠陥は1本あたり1〜6件で30〜50枚に散らばる。
枚数が多くてコストが気になるときは、1枚ずつ読むのをやめて
**コンタクトシート（4枚/枚）で全数見る**（画像のコストが約1/4になる）。

## 依存

```bash
pip install -r scripts/requirements.txt
```

加えて、システム側に **ffmpeg / ffprobe**、**LibreOffice（soffice）** が要る。
段階図を作るなら **draw.io desktop**、音声合成にはクラウドTTSの認証が要る。

## 講座固有のもの

用語規約・カリキュラム設計書・一次情報のスナップショットは**講座リポジトリ側に置く**。
このプラグインは作り方（ハーネス）だけを持つ。次も講座側に置く：

- 映り込みの規則ファイル（`templates/leak_rules.example.yaml` から作る。**git 管理外**）
- 制作の教訓ファイル（`templates/course-lessons.md` から作る。座学と実践で1つ）
- TTS モデルの既定（環境変数 `VIDEO_COURSE_TTS_MODEL`）、照合先のエンドポイント（環境変数 `SPEECH_ENDPOINT`）。
  API キーなどの秘密情報はリポジトリの外に置き、画面・ログ・コミットに出さない

## 変更履歴

### 0.3.0

資格講座1本（座学49本・実践19本）を作り、実践13本を撮り直した実測から反映した。

- **黙って失敗しない**：TTS に失敗した区間があると終了コード 1 で止まり、動画を組まない（以前は無音の静止画で組んで 0。
  503 の2枚が無音のまま公開候補になった）。起動時に依存とどの Python で動いているかを確かめる（`deps.py`。
  PATH の Python が入れ替わって処理が黙って抜けた）。`requirements.txt` に `verify_tts.py` の依存を足した
- **音声の manifest**：本文のハッシュ・モデル・声を記録する。座学も本文が変わった区間だけ作り直す
  （台本を直したのに古い音声のまま組まれ、強調のきっかけ10件が照合に落ちた）。既存の音声と違うモデルで作ろうとすると
  止まる（モデルを切り替えたとき、変わらない区間が古いモデルのまま残った）
- **verify_tts**：認証のタイムアウトを 60 秒にし、全区間が「認識結果が空」のときは照合先の故障（終了コード 3）として
  NG と分ける（照合先のリソースが別の講座の後片付けで消え、全区間が NG になった）。座学の speech_NN の対応を直した
- **完成動画の検査**：`empty_frames.py`（承認済みの3本にも空白が見つかった）、`still_report.py`
  （20 秒を超えて静止するスライドが 242 枚）、`final_sweep.py`、`cue_report.py`（3,206 件中 64 件が補間、最大 26 秒のずれ）、
  `cue_drift.py`（誤一致で最大 27 秒のずれ）
- **実践の撮影**：管理コンソール主体・手前を撮る・URL で直接飛ばない、を既定にした（CLI 先行の形で撮った13本を撮り直した）。
  デスクトップに触らない規則、撮影が止まったら先にリソースを消して報告、後片付け（同名の確認・RG の外に残るもの・
  一覧 0 件の画面）、課金を断定しない書き方
- **OCR による黒塗りと全数点検**（`ocr_mask.py`・`leak_check_ocr.py`）、**寸法の検査つき取り込み**（`ingest_shot.py`）
- **リファレンスとテンプレート**：品質の基準、TTS の事故の形、自己改善の仕組み、撮り直しの依頼文、教訓ファイル
