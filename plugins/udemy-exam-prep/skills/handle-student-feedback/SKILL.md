# handle-student-feedback

公開済みの練習問題集に受講者から指摘が来たときの対応手順。修正の順序は **CSV → Udemy → 公開 → 返信**。CSV が正本。

## 原則

- **指摘は症状であって、範囲ではない。** 1件を直して終わりにせず、同じ原因が講座全体にないかを調べる（実績: 3件の指摘の背後に、正解の誤り18問・陳腐化21問・範囲外10問・軽微54問があった）
- **受講者の主張も一次情報で確かめる。** 正しい部分と誤解を切り分け、返信でも区別して書く（実績: 「旧構成の型が答え」という指摘は、旧構成については正しく、現行の構成を問う問題としては誤りだった）
- 修正済み・公開済みと返信してよいのは、**公開が完了したあと**

## 手順

1. **指摘を一覧にする**: Q&A（`https://www.udemy.com/instructor/communication/qa/`）で未読フィルタを外して確認する。別コースの質問が混ざるので、対象の講座だけ拾う。各指摘について「どの問題か（関連質問から特定）」と「主張」を書く
2. **一次情報で検証する**: 主張ごとに、現行の公式ドキュメントで正否を判定する（[[research-cert-docs]]）。判定は「正しい／一部正しい／誤解」
3. **講座全体を見直す**（範囲はユーザーが決める）: 全問を一次情報と照合する
   - サブエージェントを領域ごとに並列起動し、レポートは**ファイルに書かせる**（戻り値は16,000字で切れる。サブエージェントは Write を持たないので、`python` の `json.dump` で書かせ、返信前に `json.load` で確認させる）
   - 分類は ERROR（正解が誤り・正解が複数）、STALE（陳腐化）、SCOPE（出題範囲外）、MINOR（解説の不正確・出典切れ）
   - 機械検査を全問にかける: `python "${CLAUDE_PLUGIN_ROOT}/scripts/validate_quiz_csv.py" <quiz.csv>`（Markdown 記法、選択肢の番号参照。改行は警告）と、[[exam-validator]] の検証
   - 同一試験内で同じ概念を2問で出していないかも見る
4. **CSV を修正する**: 修正は差分（PATCH の JSON）にし、選択肢数・正解数・出典 URL・解説の正誤宣言と `Correct Answers` の矛盾を機械検証してから適用する。適用後に検証を通し、question-bank.md と sources.md を同期する
5. **Udemy に反映する**: [[udemy-bulk-upload]]「多数の問題を書き換える」（Claude in Chrome を第一手段に、1本ずつ・1タブで）。全問を `auditBg` で CSV と照合する
6. **公開する**: 更新メッセージを入れて公開する（[[udemy-bulk-upload]]「公開」）。`udemy-course-meta.md` の更新履歴に、日付・内容・検証結果・更新メッセージを追記する（[[upload-practice-tests]]「更新履歴を残す」）
7. **返信する**: 指摘ごとに、公開が済んでから返信する

## 返信の書き方

構成は、宛名 → 感謝と誤りかどうかの明言 → 正しい内容 → 直した内容 → 結び。段落は空行で分ける。

- 誤りは「誤りでした。申し訳ありません」と明言する。誤解の場合は責めず、根拠を示す
- 正しい内容は具体的に書く（型名・設定名・値）。出典のない断定や数値は書かない
- 「実際の試験に出るか」は断定しない。公式の出題範囲に基づいて説明する
- 指摘ごとに別のスレッドへ返信する。別コースのスレッドには返信しない

## Q&A 画面の操作

- 返信欄の座標は、スクリーンショットで確認してクリックする。JS の座標は縮尺が違い、外すと入力が空白キーでスクロールされる
- クリック後に `document.activeElement` が `contenteditable="true"` かつ `role="textbox"` で、対象スレッドの中にあることを確認してから入力する
- 入力後にスクリーンショットで内容を確認してから「投稿」を押す。投稿後に「1件の回答」と出ることを確認する

## 確認を取る場面

| 操作 | 理由 |
|---|---|
| 講座全体の見直しの範囲 | 工数が大きい |
| Udemy の公開 | 受講者に見える |
| Q&A への返信 | 公開の発言になる |

ユーザーが「公開して返信して」のように事前に指示している場合は、その範囲で進めてよい。Udemy の公開は、プロジェクトの `CLAUDE.md` が公開を自動化の対象にしていればそれに従う。
